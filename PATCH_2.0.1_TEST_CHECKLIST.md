# LifeOS Web 2.0.1 Manual Check List

After running the patched source, switch to Dark theme and verify:

## Reported Screens

- Routine: search, Day, Type, Course, and Sort remain inside the filter card and wrap cleanly.
- Attendance: Course, Status, and Sort labels are clearly readable.
- Dashboard: Weekly Performance and Achievement Progress labels/values are clear.
- Calendar: dates, headers, grid lines, today, selected date, and event chips are easy to distinguish.

## Wider Color Sweep

- Academic target/degree blocks
- Attendance course cards and circular progress
- Habit controls
- Focus settings and checklist
- Notes editor/preview
- Search history/results
- Analytics factor and insight rows
- Report builder controls
- Modals, forms, tables, and empty states

## Responsive Checks

Use Chrome DevTools at:

- 360 px
- 390 px
- 768 px
- 1024 px
- Desktop width

No filter should leave its card or appear behind another section.
