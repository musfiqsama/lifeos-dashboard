# LifeOS Premium UI Redesign

Changed in this version:

- Rebuilt the visual system with a premium dark glassmorphism theme.
- Added gradient typography, glowing cards, refined sidebar, improved landing page, and responsive layouts.
- Preserved all existing React logic, data storage, routes, pages, and features.
- Improved mobile behavior for sidebar navigation, cards, grids, reports, badges, calendar, timer, and landing page.

Run locally:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
