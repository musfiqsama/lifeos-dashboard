# LifeOS Web 2.0 — User Guide

## First Run

1. Run `npm install` and `npm run dev`.
2. Open the URL shown in the terminal.
3. Select **Enter Workspace** on the landing page.
4. Open **Settings & Data** to set your name, university, department, theme, density, language foundation, date format, and week start.

## Recommended Setup Order

1. **Academic:** configure grading scale and add courses.
2. **Routine:** add weekly classes and link them to courses.
3. **Attendance:** mark class attendance manually or from today’s routine.
4. **Tasks/Goals/Exams:** add deadlines, milestones, subtasks, and preparation topics.
5. **Habits/Focus:** configure daily targets and focus settings.
6. **Notes/Resources:** organize course knowledge and safe external links.
7. **Calendar/Reminders:** review the unified schedule and notification settings.
8. **Analytics/Reports:** review progress and export printable reports.

## Backups

Open **Settings & Data** and select **Export Backup**. Keep the JSON file private. To restore, select **Import Backup** and choose a current or legacy LifeOS JSON backup.

## PDF Reports

Open **Reports**, choose a preset or custom sections, then use **Print / Save as PDF** in the browser print dialog.

## External Links

LifeOS permits `http`, `https`, and `mailto` resource links. Unsupported or unsafe protocols are rejected or removed during data migration.

## Mobile Navigation

The bottom navigation contains the most-used modules. Select **More** for the complete module list. The sheet supports Escape, keyboard focus trapping, backdrop close, and body-scroll locking.
